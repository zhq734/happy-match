# 开心消消乐 · Happy Match

一款使用 **Vite + TypeScript** 从零实现的网页版三消游戏，支持多关卡与**每关不同的玩法机制**。

> 纯前端、零运行时依赖、无需任何外部素材（音效由 WebAudio 实时合成，图形由 CSS 绘制）。

## ✨ 特性

### 多玩法模式
| 模式 | 说明 | 示例关卡 |
| --- | --- | --- |
| 🎯 步数挑战 | 限定步数内达成目标 | 第 1、6 关 |
| ⏱ 限时冲刺 | 倒计时内尽可能得分 | 第 4、10 关 |
| 🍬 收集目标 | 收集指定颜色糖果 | 第 3、11 关 |
| 🧊 清障挑战 | 清除全部果冻 / 冰层 | 第 2、5、7、9、12 关 |
| 🍰 食材运送 | 把食材从顶部运到底部出口 | 第 8、11 关 |

### 三消核心机制
- **三消匹配**：横向 / 纵向 / L 形 / T 形自动合并识别
- **特殊糖果**：
  - 四消 → **条纹糖**（清除整行或整列）
  - 五消 → **彩虹糖**（清除全场同色）
  - L / T 形 → **包装糖**（爆炸清除周围一圈）
- **组合技**：两颗特殊糖果交换触发强化效果（双条纹十字清除、彩虹 + 任意糖果全屏同色、包装 × 2 范围爆炸等）
- **连锁反应**：消除后自动下落补给，连锁层级越高得分倍率越高
- **智能洗牌**：无可行移动时自动重排，保证游戏可继续
- **提示系统**：一键高亮一个可行交换

### 关卡地形
- 空洞（`#`）— 不可放置方块
- 冰层（`i` / `I`）— 需在相邻位置消除来击碎
- 果冻（`j` / `J`）— 需在该格完成消除来清除
- 食材出生点（`s`）与出口（`e`）

### 体验细节
- 📱 响应式自适应：棋盘按容器尺寸实时计算格子大小，手机 / 平板 / 桌面通用
- 🌗 明暗双主题：跟随系统或手动切换，全部样式基于 CSS 变量
- 🔊 程序化音效与背景音乐（WebAudio 合成，无音频文件）
- 💾 本地存档：关卡星级、最高分、解锁进度、设置项持久化
- ✨ 动效：拖拽交换、消除爆裂粒子、飘分、连锁横幅、星级弹出
- ♿ 无障碍：支持键盘解锁音频、`prefers-reduced-motion` 降级动画

## 🎮 操作方式

- **拖动**相邻两个糖果交换位置
- 或**依次点击**两个相邻糖果完成交换
- 底部按钮：提示 / 洗牌 / 重开 / 暂停

## 🚀 本地运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 生产构建
npm run preview    # 预览构建产物
npm test           # 运行单元与集成测试
npm run typecheck  # 类型检查
```

## 🧪 测试

采用 TDD 方式开发，共 **39 项测试**：

- `tests/board.test.ts` — 棋盘引擎：匹配识别、特殊糖果生成、组合技、冰/果冻、食材运送、无解洗牌
- `tests/session.test.ts` — 会话逻辑：胜负判定、步数/计时、目标进度、提示
- `tests/progress.test.ts` — 存档：星级累计、解锁规则、最高分保留
- `tests/integration.test.ts` — jsdom 集成冒烟：首页渲染、关卡选择、棋盘渲染、真实点击交换并得分

```bash
npm test
```

## 📁 项目结构

```
src/
├── game/
│   ├── board.ts      # 三消棋盘引擎（匹配 / 特殊糖果 / 重力 / 连锁）
│   ├── session.ts    # 游戏会话（目标、胜负、计时）
│   ├── levels.ts     # 12 个关卡配置
│   ├── types.ts      # 核心类型
│   └── rng.ts        # 可复现随机数
├── ui/
│   ├── boardView.ts  # 棋盘渲染与交互动画
│   ├── gameScreen.ts # 游戏界面与 HUD
│   ├── levelMap.ts   # 关卡地图
│   ├── home.ts       # 首页与设置
│   ├── theme.ts      # 主题管理
│   └── background.ts # 背景装饰
├── audio/sound.ts    # WebAudio 合成音效
├── storage/progress.ts # 本地存档
├── style.css         # 设计令牌与全部样式
└── main.ts           # 应用入口
```
